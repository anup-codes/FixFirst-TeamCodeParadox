FixFirst – "Priority-Based Issue Management System"
📌 Project Overview

FixFirst is a priority-based issue management system designed to help administrators efficiently track, manage, and resolve user-reported issues. 
The platform categorizes issues based on priority levels, ensuring that critical problems are addressed first with real-time status tracking.

This project was developed as part of a hackathon, focusing on practical problem-solving, clean UI, and effective issue handling workflows.

🎯 Key Features

🧾 User issue submission system

🚨 Priority-based issue categorization (High / Medium / Low)

📊 Real-time issue status tracking

👨‍💼 Admin dashboard for managing and resolving issues

🔐 Secure authentication system

📱 Responsive and user-friendly UI

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend / Services: Firebase (Authentication & Firestore)

Hosting: Netlify

🧠 Problem It Solves

* Many issue-tracking systems fail to highlight critical problems efficiently.
* FixFirst ensures high-priority issues receive immediate attention,
  improving response time and overall system reliability.
